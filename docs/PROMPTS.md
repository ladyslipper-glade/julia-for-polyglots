
PROMPTS
=======

This file contains the prompts I used to create this tutorial. The content generated in this way was only the starting point. I edited the generated text to correct errors and clarify the presentation. These prompts are here for documentation only and to serve as potential starting points for additional work.

## Skeleton

The first prompt took me from an empty repository to a repository containing skeleton files. I used Perplexity Computer.

---

The GitHub repository ladyslipper-glade/julia-for-polyglots is intended to contain a tutorial for the Julia programming language that focuses on learners who already know two or more programming languages. The repository is currently a near-empty shell.

Add content to the repository to provide infrastructure for the tutorial. Do not add any tutorial content at this time.

Add or update the following items:

1. A `Project.toml` file declaring necessary packages.
2. A `notebooks` folder containing 8 to 12 skeletal Pluto notebooks. These notebooks do not need any content, but they should be valid Pluto notebook files. They should have names reflective of appropriate tutorial topic areas. Each name should be prefixed with a two digit number (01, 02, etc.) so they naturally sort in an appropriate order for reading.
3. An updated `README.md` that describes the tutorial and provides instructions suitable for a newcomer to Julia for setting up Pluto for use in Visual Studio Code.

---

## Chapter 1

This prompt generated the initial content for the first chapter

---

The GitHub repository ladyslipper-glade/julia-for-polyglots is intended to provide a tutorial for the Julia programming language for learners who already know two or more programming languages. The repository is currently a near-empty shell.

Add content to the first Pluto notebook in the tutorial, `01-getting-started.jl`. Make sure the file remains a valid notebook file. The content should be no more than approximately 5000 words and should include information on topics such as the history of Julia, what kind of applications Julia is good for, how to get set up to use Julia, and a few short examples of what Julia can do to interest and motivate the reader without being overwhelming. Keep in mind that the reader already knows basic programming concepts, but is not yet familiar with Julia syntax and semantics.

Do not change any other files others than `01-getting-started.jl`. Submit your new content as a pull request to the GitHub repository.
